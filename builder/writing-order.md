# Порядок написания текущего сайта

## 1. Подготовь Open Server Panel и базу

Запусти PHP и MySQL в Open Server Panel. Создай папку conf в каталоге своего сайта. В phpMyAdmin создай базу conferences, таблицы users и requests, индексы и связь. Подробные действия кнопками и формами находятся на странице «БД через phpMyAdmin».

database.sql — дополнительный вариант создания той же схемы через импорт в новую пустую базу. Данные из рабочей базы в пакет не включены.

## 2. Напиши db.php

Создай класс Database с методом connect. Подключись к MySQL через PDO: адрес сервера, имя базы conferences, пользователь root и локальный пароль. Затем вызови session_start, создай объект Database и получи подключение через его метод connect. Добавь e для вывода текста в HTML и require_login для закрытых страниц.

## 3. Напиши header.php, footer.php и style.css

В шапке нужны кодировка UTF-8, viewport, название вкладки, локальные Bootstrap и style.css, заголовки и меню по роли. В footer закрой main, body и html. В стилях подключи локальный PT Sans. Класс auth-page на body центрирует страницы входа и регистрации; min-height вместо фиксированной высоты позволяет длинной форме прокручиваться.

## 4. Напиши register.php

При GET покажи форму. При POST прочитай поля из $_POST, проверь логин, пароль, ФИО, телефон и email. Найди совпадения логина или email. Если их нет, выполни INSERT, сохрани пароль через password_hash и перенаправь на index.php?registered=1. Перед подключением шапки задай auth_page = true. У формы нет col-md-6: ширина задаётся общим центральным блоком.

## 5. Добавь phone.js

Подключи локальный скрипт с defer в register.php. Поле телефона имеет inputmode numeric, maxlength 15 и pattern для полного номера 8(XXX)XXX-XX-XX. formatPhone добавляет скобки и дефисы к цифрам. Обработчик input удаляет буквы и восстанавливает курсор. Обработчик paste отдельно форматирует вставленный номер. Проверка PHP обязательна: маска браузера не заменяет проверку перед INSERT.

## 6. Напиши index.php и logout.php

На входе найди пользователя по логину подготовленным SELECT. Проверь пароль через password_verify. После успеха обнови ID сессии и запиши user_id и role. Администратора перенаправь в admin.php, пользователя в requests.php. auth_page = true включает центрирование. Для выхода открой сессию, очисти её, вызови session_destroy и перенаправь на вход.

## 7. Напиши create.php

Сначала require_login. Прочитай помещение, дату и способ оплаты. Проверь длину, точный формат и существование даты через DateTime, способ оплаты — по списку. INSERT записывает user_id из сессии, а дату переводит в формат MySQL.

## 8. Напиши requests.php

Выбирай только строки с user_id текущей сессии. Показывай их через foreach. Форму отзыва выводи для статуса «Завершено». В UPDATE одновременно проверяй ID заявки, владельца и статус.

## 9. Напиши admin.php

Проверь вход и роль admin. JOIN связывает заявки с данными пользователей. Для каждого запроса покажи список разрешённых статусов. После POST проверь выбранное значение, выполни UPDATE по ID и перенаправь на эту же страницу.

## 10. Проверь работу

Проверь регистрацию, повторный логин или email, ошибочный пароль, вход пользователя, создание заявки, список только своих заявок, смену статуса администратором, отзыв после завершения и выход. В телефоне проверь буквы, вставку, удаление и неполный номер. На узком экране форма должна помещаться без горизонтальной прокрутки. Для работы PHP сайт открывают через локальный сервер Open Server Panel.

Все актуальные файлы с подробными комментариями находятся на странице «Файлы примера». Встроенный ZIP содержит те же исходники и локальные ресурсы.
