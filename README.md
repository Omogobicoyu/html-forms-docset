# HTML (Русский) для Zeal и Dash

Неофициальный русский перевод справочника MDN HTML с тем же значком HTML5.
Версия пакета: **2026.11.19.1**. Архив: около 83 МиБ.

1233 статьи; перевод преимущественно автоматический (Argos en-ru 1.9), 233 вводных
абзаца взяты из русских переводов MDN. В переводе возможны неточные формулировки.
3582 исходных блока кода MDN сохранены. Это снимок HTML revision 157, а не официальный
перевод Mozilla или Kapeli и не постоянно обновляемая копия живого MDN.

## Установка в Zeal

1. Открой **File → Docset Library → Installed → Add feed**.
2. Вставь [короткую ссылку](https://is.gd/htmlru27) или полный адрес:

```text
https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTML_RU.xml
```

3. Дождись загрузки **HTML (Русский)**. Уже добавленный feed можно обновить до версии
   2026.11.19.1; если Zeal не предлагает обновление, удали только этот пользовательский
   справочник и добавь тот же feed снова.

Адрес feed не изменился. Статьи и вложенный код доступны без интернета. Внешние
ссылки на источники и отдельные аудио/видео требуют интернета и не загружаются автоматически.
