# HTML (Русский) для Zeal

Русская копия стандартного справочника HTML, установленного в Zeal (MDN, revision 157), с тем же значком HTML5. Английский оригинал не заменяется.

В пакете 1233 статьи MDN, включая HTML и связанные API. Перевод преимущественно автоматический, выполнен локальной моделью Argos Translate. 233 вводных абзаца взяты из русских переводов MDN. Возможны неточные формулировки машинного перевода. Теги, атрибуты и программный код сохраняются.

## Установка по ссылке

1. Открой **Zeal**.
2. Выбери **File → Docset Library**. В старых версиях: **Tools → Docsets**.
3. На вкладке **Installed** нажми **Add feed**.
4. Вставь целиком адрес:

```
https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTML_RU.xml
```

5. Подтверди добавление и дождись загрузки. Архив весит около 83 МБ. В библиотеке появится **HTML (Русский)**.

После загрузки статьи и вложенный код доступны без интернета. Ссылки на внешние сайты требуют интернета.

## Где находится пример

Введи в поиске Zeal:

```
htmlru:form
```

Открой элемент **form**. На странице найди раздел **Примеры** и раскрой **Практический пример: формы и серверный обработчик**. Нажми **Открыть полный пример с файлами**.

Внутри находятся 11 точных файлов финального сайта «Конференции.РФ». Каждый файл раскрывается отдельно. Также есть инструкция создания БД **через интерфейс phpMyAdmin**, порядок написания сайта и ZIP с кодом, Bootstrap и локальными шрифтами.

PHP в Zeal показан как текст. Для запуска нужен Open Server Panel с PHP и MySQL. Код сайта в этом пакете не менялся.

## Если нужна ручная установка

Скачай [HTML_RU.tgz](https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTML_RU.tgz). Распакуй архив: внутри будет папка `HTML_(Русский).docset`. Помести её в каталог docsets из настроек Zeal и перезапусти Zeal. У установленного Windows-приложения это обычно `%LOCALAPPDATA%\Zeal\Zeal\docsets`.

## Источники и лицензии

Это неофициальная модификация. Тексты: Mozilla Contributors, CC BY-SA 2.5 или более поздняя версия. На каждой статье есть ссылка на исходную страницу и отметка о переводе. Готовые русские вводные абзацы: [mdn/translated-content](https://github.com/mdn/translated-content).

Клиентские ресурсы [MDN Fred](https://github.com/mdn/fred) — MPL-2.0; полный текст лицензии включён в архив. HTML5 logo — W3C, CC BY 3.0. Лицензии и ссылки сохранены в `LICENSES.txt`. Закрытые метаданные Kapeli не распространяются; индекс поиска построен заново из статей.

## Проверки пакета

Проверены целостность SQLite, пути поиска, сохранение всех 3582 блоков кода MDN, точное совпадение 11 файлов сайта и закрытый по умолчанию блок с примером. Проверка импорта нового пакета в интерфейсе Zeal не завершена: управление окном приложения оказалось недоступно.

Предыдущий небольшой пакет HTML Forms доступен отдельно: [старый feed](https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTMLForms.xml).
