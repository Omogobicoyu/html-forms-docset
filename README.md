# HTML Forms для Zeal

Личный офлайн-справочник по HTML с примерами HTML-форм и PHP. Отдельный пакет: не заменяет стандартный HTML.docset.

## Установка по ссылке

Открой библиотеку справочников Zeal: **File → Docset Library** в новых версиях или **Tools → Docsets** в старых. Выбери **Installed → Add feed** и вставь:

```
https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTMLForms.xml
```

Дождись установки **HTML Forms**. После скачивания интернет для чтения не нужен.

## Поиск и пример

Поиск: `htmlforms:form`.

На странице **form: отправка данных** раскрой **Практический пример: формы и серверный обработчик**. Перейди по ссылке полного примера и раскрывай нужные файлы. Внутри 11 файлов финального портала, инструкция создания БД через интерфейс phpMyAdmin и исходники с локальными ресурсами в ZIP.

PHP в Zeal не выполняется: это текст кода для чтения и копирования. Запускать пример нужно в Open Server Panel с MySQL.

## Ручная установка

Скачай HTMLForms.tgz или локальный HTMLForms-manual.zip. Распакуй так, чтобы получилась папка HTMLForms.docset. Помести её в каталог docsets, указанный в настройках Zeal, и перезапусти Zeal. В Windows установленной версии часто используется `%LOCALAPPDATA%\Zeal\Zeal\docsets`, но ориентироваться нужно на фактические настройки.

Пакет проверен на целостность SQLite-индекса, ссылки, пути архива и точное совпадение кода с финальным проектом.

Формат пакета: https://kapeli.com/docsets
Zeal: https://zealdocs.org/
