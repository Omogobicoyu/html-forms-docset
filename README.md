# HTML (Русский) для Zeal и Dash

Неофициальный русский перевод справочника MDN HTML с тем же значком HTML5.
Версия пакета: **2026.11.19.1**. Архив: около 83 МиБ.

1233 статьи; перевод преимущественно автоматический (Argos en-ru 1.9), 233 вводных
абзаца взяты из русских переводов MDN. В переводе возможны неточные формулировки.
3582 исходных блока кода MDN сохранены. Это снимок HTML revision 157, а не официальный
перевод Mozilla или Kapeli и не постоянно обновляемая копия живого MDN.

## Установка в Zeal

1. Открой **File → Docset Library → Installed → Add feed**.
2. Вставь [короткую ссылку](https://is.gd/htmlru27) или полный адрес:

```text
https://raw.githubusercontent.com/Omogobicoyu/html-forms-docset/main/HTML_RU.xml
```

3. Дождись загрузки **HTML (Русский)**. Уже добавленный feed можно обновить до версии
   2026.11.19.1; если Zeal не предлагает обновление, удали только этот пользовательский
   справочник и добавь тот же feed снова.

Адрес feed не изменился. Статьи и вложенный код доступны без интернета. Внешние
ссылки на источники и отдельные аудио/видео требуют интернета и не загружаются автоматически.

## Где текущий код

Поиск **`htmlru:form`** → элемент **form** → раздел **Примеры** →
**Практический пример: формы и серверный обработчик** → **Открыть полный пример с файлами**.

Каждый файл раскрывается отдельно. Внутри 12 файлов: 9 PHP, `style.css`, `phone.js`
и дополнительный `database.sql`. PHP/CSS/JS точно соответствуют сайту от 19.11.2026:
подробные русские комментарии, вход и регистрация по центру, маска телефона
`8(XXX)XXX-XX-XX` с удалением букв. Встроенный ZIP содержит все 17 текущих файлов
сайта, включая Bootstrap, шрифты и диаграмму, и дополнительную схему новой базы.

Есть пошаговое создание таблиц через интерфейс **phpMyAdmin** и порядок написания
сайта. PHP и JavaScript исходников показываются текстом, внутри справочника они
не выполняются. Для запуска сайта нужен Open Server Panel с PHP и MySQL.
Рабочие записи пользователей в пакет не входят.

## Пакет для подачи в Dash

[Подготовленные файлы](dash/) и [пошаговая подача](dash/SUBMIT_TO_DASH.md).
В `dash/docsets/HTML_(Русский)` находятся архив, `docset.json`, README и два значка;
рядом — готовые заголовок и описание pull request. Эти файлы подготовлены,
но pull request в Kapeli ещё не отправлен и пакет не принят в общий каталог.
Наличие учебного PHP/MySQL-проекта указано в описании для сопровождающего.

[Правила каталога](https://github.com/Kapeli/Dash-User-Contributions/wiki/Docset-Contribution-Checklist)
требуют публичной полезности и дальнейшей поддержки справочника. Импорт в настоящий
Dash на macOS пока не проверен; это явно отмечено в описании подачи.

## Проверки

SQLite, все 3405 путей и якорей поиска, безопасные пути TAR и 3582 исходных блока
MDN. 139 примеров mdnplay восстановлены из исходников, записанных в их ссылках.

и 1100px с заблокированным внешним интернетом. Намеренные отсутствующие изображения
в демонстрациях ошибок MDN сохранены.
