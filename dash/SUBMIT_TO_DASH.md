# Подача HTML (Русский) в каталог Dash

Пакет подготовлен для подачи. Pull request в Kapeli не отправлен.

## Что уже лежит в этой папке

- `docsets/HTML_(Русский)/HTML_(Русский).tgz` — готовый справочник.
- `docsets/HTML_(Русский)/docset.json` — метаданные по образцу Dash.
- `docsets/HTML_(Русский)/README.md` — автор, исходники, полная инструкция сборки, лицензии и известные ограничения.
- Два значка: 16×16 и 32×32.
- `PR_TITLE.txt` и `PR_BODY.md` — готовые заголовок и описание подачи.
- `CHECKS.md` — результаты проверок и оставшаяся проверка на macOS.

## Как подать

1. Открой https://github.com/Kapeli/Dash-User-Contributions и сделай Fork в свой аккаунт.
2. Скачай или клонируй свой fork. Создай в нём ветку `add-html-russian`.
3. Скопируй папку `docsets/HTML_(Русский)` из этого пакета в папку `docsets` своего fork. В ней должны быть архив, JSON, README и оба значка.
4. Сохрани эти пять файлов одним коммитом и отправь ветку в свой fork.
5. Создай Pull request в `Kapeli/Dash-User-Contributions`, целевая ветка `master`. Заголовок возьми из `PR_TITLE.txt`, описание — из `PR_BODY.md`.
6. Перед отправкой проверь импорт на Mac с Dash и добавь реальный результат в описание. Если Mac пока нет, оставь честную отметку о непроверенном импорте — она уже есть в заготовке.
7. Дождись решения сопровождающего и отвечай на замечания. Появление в каталоге и в Zeal зависит от принятия и распространения пакета; подготовка файлов сама по себе этого не делает.

Официальные требования: https://github.com/Kapeli/Dash-User-Contributions/wiki/Docset-Contribution-Checklist
Инструкция подачи: https://github.com/Kapeli/Dash-User-Contributions#contribute-a-new-docset
Версии: https://github.com/Kapeli/Dash-User-Contributions/wiki/Docset-Versioning-Guidelines

## Где текущий код внутри справочника

Поиск `htmlru:form` → элемент form → раздел «Примеры» → «Практический пример: формы и серверный обработчик» → «Открыть полный пример с файлами».

Каждый файл раскрывается отдельно. Здесь именно текущие PHP/CSS/JS с комментариями, центральным расположением входа/регистрации и маской телефона. ZIP содержит все 17 файлов текущего сайта и дополнительную схему database.sql. Рабочие данные пользователей не включены.

В описании для проверяющих Dash учебный пример указан открыто. Это неофициальный преимущественно машинный перевод MDN. После принятия требуется поддерживать справочник и исправлять поступающие ошибки согласно правилам каталога.
